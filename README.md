# Phalanx

A secure, private and battery-friendly Matrix client for Android, built on the [Matrix Rust SDK](https://github.com/matrix-org/matrix-rust-sdk) with strict Material 3 Expressive design.

- **No Google services.** Push is UnifiedPush; there is no FCM, no Play Services, no telemetry.
- **Messaging only.** No voice or video calls.
- **Status:** project skeleton. Login, room list and timeline are next.
